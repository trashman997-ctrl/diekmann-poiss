# Diekmann & Poiss — Business Card Website

A minimalist, single-page business card site for **Diekmann & Poiss**, a startup specializing in **building greenery solutions** and **custom software for vertical garden planning**.

---

## 🌱 About the Project
This website serves as a digital business card, showcasing our mission, services, and contact information. It is built using the **Tessellate** template by [HTML5 UP](https://html5up.net), customized to fit our brand and needs.

---

## ✨ Key Features
- **Hero Section**: Company name, tagline, and SVG mockups of our planning software UI.
- **What We Do**: Four service descriptions in a clean, numbered list.
- **Contact**: Email links, profile photos, and LinkedIn links for both founders.

---

## 🛠 Technologies
- **[TanStack Start](https://tanstack.com/start)** — React full-stack framework (file-based routing, SSR)
- **[Tailwind CSS v4](https://tailwindcss.com)** — Utility-first styling
- **[Vite](https://vitejs.dev)** — Build tool
- **Deployed on [Netlify](https://netlify.com)**
