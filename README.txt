# Diekmann & Poiss — Business Card Website

A minimalist, single-page website for **Diekmann & Poiss**, showcasing our work in **building greenery solutions** and **custom software for vertical garden planning**.

Built with the **[Tessellate](https://html5up.net/tessellate)** template by [HTML5 UP](https://html5up.net).

---

## 📌 Features
- Hero section with company name, tagline, and SVG mockups
- "What We Do" section with service descriptions
- Contact section with email and LinkedIn links

---

## 🛠 Tech Stack
- **Template**: [Tessellate by HTML5 UP](https://html5up.net/tessellate) (CCA 3.0 License)
- **Styling**: Tailwind CSS v4
- **Build Tool**: Vite
- **Deployment**: Netlify
